## Presentación

Este espacio contiene la documentación de arquitectura de software de AgroSmart Insights.

La documentación utiliza el marco arc42 para organizar la descripción del sistema, sus objetivos, restricciones, contexto, componentes, flujos de ejecución, infraestructura, decisiones arquitectónicas y requisitos de calidad.

## Contenido

- Documentación general de arquitectura basada en arc42.
- Diagramas de arquitectura general, RAG y conectividad híbrida (Ngrok).
- Arquitectura de microfrontends con Module Federation (`agrosmart-frontend` + 5 microfrontends remotos).
- Decisiones arquitectónicas (ADRs).
- Información sobre los workflows de n8n (`WF0`, `WF1`, `WF2`, `WF3`, `WF4` y `WF5`).

## Objetivo

Mantener una documentación organizada, comprensible y actualizable que represente la arquitectura del proyecto durante su evolución.
